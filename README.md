# ✻ Вітальня — лаунчер для Android TV приставки

Головний екран у стилі терміналу: годинник, погода, статус тривоги у твоєму регіоні, онлайн-мапа тривог України (реальні контури областей), лог подій і док із програмами (LAMPA, YouTube, MEGOGO, Київстар ТБ, sweet.tv, uakino, Netflix, Prime Video — підхоплюються автоматично, якщо встановлені).

Розраховано під X96Q Max Pro (Android 10); мінімум — Android 5.

## Що вміє
- **Годинник, дата, погода** (Open-Meteo, без ключів).
- **Тривоги**: оновлення кожні 30 с. Червоний — тривога по області, жовтий — частково (лише з токеном alerts.in.ua). Твій регіон обведений.
- **Сповіщення**: коли тривога починається у твоєму регіоні — на весь екран червоний банер + сирена (вимикається в налаштуваннях). Відбій — зелене сповіщення.
- **Лог** змін («тривога · Сумська обл.», «відбій · …»).
- **Док програм**: банери/іконки беруться із системи. ▦ — усі програми; там «✎ Редагувати док» → OK ставить/знімає ★.
- **Налаштування** (⚙): твій регіон, звук, системні налаштування Android.
- Кнопка «Назад» не закриває лаунчер, «Home» завжди повертає сюди.

## Як зібрати APK (без Android Studio, ~5 хв)
1. Зайди на github.com → **New repository** → назва `vitalnya`, **Public** → Create.
2. **uploading an existing file** → перетягни **вміст** цієї папки (не саму папку).
   ⚠️ На Mac папка `.github` прихована: у Finder натисни **Cmd + Shift + .**, щоб її побачити, і перетягни теж.
3. **Commit changes**. Відкрий вкладку **Actions** — збірка «Build APK» стартує сама (3–4 хв, має стати зеленою ✓).
4. Готовий файл: **Releases → latest → vitalnya.apk**. Пряме посилання:
   `https://github.com/<твій-логін>/vitalnya/releases/download/latest/vitalnya.apk`

## Як поставити на приставку
1. На приставці встанови **Downloader** (з Play Market) або відкрий браузер.
2. Введи пряме посилання з кроку 4 → завантаж → Встановити (дозволь «невідомі джерела», якщо спитає).
3. Натисни **Home** на пульті → обери **Вітальня** → **Завжди**.
   Якщо вибір не з'явився: Налаштування → Програми → Програми за замовчуванням → Головний екран → Вітальня.
   Через ADB: `adb shell cmd package set-home-activity ua.vitalnya.launcher/.MainActivity`

Після перезавантаження приставка одразу відкриває Вітальню з мапою тривог.

## Налаштувати під себе
Відкрий на GitHub `app/src/main/assets/index.html` → ✏️ і зміни блок `CONFIG` угорі:
```js
name: "Макс",               // ім'я в привітанні
city: "Київ", lat: 50.4501, lon: 30.5234,  // погода
homeRegion: "kyiv_city",    // регіон за замовчуванням
alertsToken: "",            // токен alerts.in.ua — точніше, з районами
```
Commit → APK перезбирається сам → завантаж і встанови поверх (налаштування збережуться).

**Токен alerts.in.ua** (необов'язково): заявка на devs.alerts.in.ua. Без нього дані йдуть з ubilling.net.ua (лише рівень областей).

## Обмеження
- «Цілі в небі / шахеди» з відео беруться з моніторингових Telegram-каналів — відкритого API для цього немає, тому мапа показує тривоги по областях (ubilling.net.ua або alerts.in.ua).
- Голосові команди не додано.
- Сповіщення про тривогу видно, коли відкрита Вітальня (не поверх Netflix тощо).
